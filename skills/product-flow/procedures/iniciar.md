# iniciar

1. Pedir o tomar la idea en una frase (puede ser vaga).
2. Ejecutar `product_flow.py iniciar --proyecto … --idea "…"`.
3. Mostrar el informe al usuario.
4. Priorizar 2–3 preguntas ASK (por defecto usuarios, recorrido, datos).
5. Esperar respuestas o «no aplica»; no inventar requisitos `confirmada`.
6. Si hay ventana localhost, indicar la URL.
